# RoB2: what thirteen prompts asked, and what three models said

Companion data for a study of LLM-based risk-of-bias assessment. Thirteen
published RoB2 prompts, run over seventy randomized trials, on three models.
**20,160 API calls, every reply kept in full.**

Open [`index.html`](index.html) to browse. Each row is one trial; each cell links
to the prompt that was sent and to what each model answered, with its five domain
judgements shown underneath.

## What is here

| | |
|---|---|
| `asked/<prompt>/<PMID>.txt` | the prompt as assembled and sent, turn by turn |
| `said/<prompt>/<PMID>.<model>.txt` | the model's reply, in full |
| `judgements.csv` | the parsed domain judgements, one row per (trial, domain, prompt, model) |
| `index.html` | a browsable index of all of it |

The three models are Claude Sonnet 5, Gemini 3.1 Pro and GPT-5.6 Terra, each at a
reasoning effort calibrated so the three spend comparable thinking tokens.

## What is omitted, and why

**The trial reports are not here.** They are third-party, held under the original
publishers' terms, and not ours to redistribute. Every prompt in `asked/` has its
`<article>`, `<tables_and_figures>` and `<protocol>` blocks replaced by a line
saying how many words were removed and linking to the trial's PubMed record. The
**RoB2 guidance document** is omitted the same way; it is Cochrane's, and is at
<https://www.riskofbias.info/>.

Everything else is reproduced verbatim: the prompt scaffolding, the system
messages, the signalling questions, and every word the models wrote.

The prompts themselves are the published work of their authors, reproduced here
because they are the object of study.

## Reading the judgements

Three of the thirteen prompts (Ji, and Suster's two SigQ variants) ask only the
22 RoB2 signalling questions and never state a domain judgement. Theirs is
**derived by us**, using RoB2's own algorithm taken from the guidance document
rather than from any system's transcription of it. Those rows are marked
`parse_layer=rob2_algorithm` in `judgements.csv`. The derivation is ours, not the
system's, and it is systematically more conservative than a directly stated
judgement: where the same author's prompt asks for the domain outright, the
system says Low more often than the algorithm does.

## Caveats worth knowing before you use this

**One run per item.** Each model answered each item once. A system that is
reliably wrong and one that is merely noisy look the same here.

**Except where they did not.** 190 Gemini cells were sent twice by accident. On
whole-assessment prompts the two runs agreed on only 66% of domain judgements,
which is about the rate at which *different models* agree with each other. Where
a cell has two answers, the earlier is used.

**Some prompts reference documents they cannot see.** Three of them carry
`doc_id:` references or mention an uploaded file, artefacts of the interfaces
their authors used. They are left as published rather than patched, because a
prompt misapplying itself is a finding rather than a defect to repair.

## Provenance

Generated by `code/14_public_dump.py` in the study repository. The corpus is the
seventy-trial benchmark from Minozzi et al. (2020).
